# 2026-11 本地实验摘要

这份摘要对应 2026-11-16 至 11-17（Asia/Shanghai）的本地实验。原始轨迹、输入文件和私有 SDK 快照保存在本地；公开的 [聚合数据](experiment-2026-11.json) 不包含这些材料。

受测版本为 OpenCode v2.2.7 与 Duet 所用 Agent Runtime SDK 0.3.0 的工作区快照。SDK 通过真实 `Agent`、单 Agent、原生 `read/bash/edit/write` 与压缩配置运行，不包含 Duet 的完整产品装配。两边使用 `gpt-6-luna`、Responses、medium、相同任务输入、官方镜像和未修改的评分器。

只有首轮四题形成了完整、无连接错误且四题等权的对照，每题每种装配一次。第二轮 PDF 另有一组成对复测，但不重复加入主表。

## 观察到的差异

- **PDF 评分敏感性**：四份正式提交均保留源论文前 17 页，但官方参考 PDF 的文本表示与原文件不同，逐字文本比较失败。未修改 grader 或补分。
- **费用舍入**：首轮主要差异为一个人均费用值，精确值 `1942.025`。Python 格式化与 pandas/NumPy 舍入生成 `.03` / `.02`；任务没有明确中点规则。原第二轮成绩反转，SDK 还出现生成与自检使用不同舍入口径的情况。不能据此推断底层 SDK 故障。
- **简历不确定性**：首轮 SDK 把任期证据不足的 19 份简历归入 senior，OpenCode 放入 unsure。官方部分检查只验证目录数量，成绩不等同于 94 份简历的逐人准确率。
- **SQL 冒烟**：OpenCode 保存查询答案并通过；SDK 保存查询语句，未满足官方要求的交付形式。该题单独记录，不进入办公任务主表。

## 故障、预算与未完成部分

原计划 16 次正式执行全部有评分；第二轮出现 28 次上游请求错误。针对受影响的三个配对计划补跑六次，第一项恢复尝试仍在首个请求连接超时，编排器停止，其余五次没有执行。没有从新旧成绩中择优，也没有宣称完成 16 个有效对照。

总计归档 21 次任务运行：16 次正式、1 次恢复尝试、2 次 SQL 冒烟、2 次 PDF 接入校准。全账本包括 226 次请求尝试、197 次成功响应、29 次未知 usage。已知费用估计 $0.073153935，覆盖率约 87.2%；含未知请求预留的保守扣账为 $0.6831464，低于 $20 上限。估计不是账单，未知请求不能算作免费。

历史代理的费用估计漏计缓存写入溢价，摘要从原始 usage 重新计算。公开代码已修正未来运行的计费与保守预留；这一维护修复没有用于改变已记录任务结果。价格及费率来源见聚合 JSON 的 `pricing` 字段。

## 结论边界

观察到了装配间的差异，但没有稳定总体排名的证据。四道有目的选出的办公题、每题只有一轮完整主对照，且部分检查存在敏感性，不能外推到完整 TAC 榜单。SDK 压缩计数均为 0，小时级长任务、产品记忆、多 Agent、持久恢复和仓库级软件工程任务尚未验证。

这里发布的是实验摘要与聚合数值；完整轨迹未公开，所以外部读者无法仅凭此仓库独立复核每项案例判断。可使用平台在自己的环境与 SDK 上重新采集证据。
